FFormatReader Open a file

Formats

Open in your browser. Nothing is uploaded.

Also: drop a whole folder to browse it like a zip. Files inside archives and folders open in place, at any depth.

Garbled text (mojibake) is detected and fixed automatically, in any language: wrong code pages, UTF-8 read as GBK or Western, Russian KOI8, Arabic, Hebrew, Greek, Thai, file names in old zips, and encoded text like %E4%BD%A0 or \u4f60.
