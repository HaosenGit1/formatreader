# Sample drawings

All generated by `scripts/make-drawing-samples.py` (no third-party content):

- `site-plan-2018.dxf` (UTF-8) and `site-plan-gbk-r12.dxf` (R12, Chinese text in GBK):
  layers, a turbine block inserted 3× (rotated, scaled), arc, polyline bulge, spline, ellipse, TEXT, MTEXT.
- `turbine*`: one simple turbine mesh as binary/ASCII STL and 3MF (Z up), OBJ, PLY and GLB (Y up).
- `operations.xmind`, `layout.odg` (thumbnail), `network.vsdx` (two pages of shape text).
- `preview-only.dwg`: AutoCAD 2018 header with an embedded PNG preview (no drawing data), for the DWG preview path.
- `box.step`: a 20×10×5 mm box as an advanced B-rep with product structure (STEP AP214).
- `substation.ifc`: IFC4 project with a wall and a floor slab (extruded profiles).
- `libredwg-example-2018.dwg`: `example_2018.dwg` from the [GNU LibreDWG](https://github.com/LibreDWG/libredwg)
  test data (GPL-3.0), a real AutoCAD 2018 drawing with layers, blocks, text, dimensions and hatches.
- turbine-pad-features.dxf — written by scripts/make-dxf-features.py: solid + pattern hatch, leader, multileader, wipeout, attribute, XLINE, layout 'Sheet A1' with a viewport.
- turbine.3ds/.dae/.wrl/.amf/.usdz and turbine-scan.pcd/.xyz/.las — written by scripts/make-3d-samples.py (simplified turbine mesh; a synthetic scan of a tower over terrain).
- tower.rvt/.skp/.3dm/.sldprt — stand-ins written by scripts/make-cad-samples.mjs: filler bytes plus a preview picture stored the way each program does (OLE stream + PNG, PNG, raw DIB, JPEG).
- turbine-elevation.plt — written by scripts/make-plt-sample.py: HP-GL/2 inside a PJL/PCL wrapper (pens, circle, fills, labels, a PE-encoded polyline).
- sensor-board.gtl/.drl — scripts/make-gerber-samples.py (Gerber X2 copper with pour + cut-out; Excellon drill).
- site-plan.dwf/.dwfx — scripts/make-dwf-samples.py (DWF V6 with two titled sheet previews; DWFx = the XPS sample, as DWFx is an XPS package).
