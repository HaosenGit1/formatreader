# Windows event log samples

These three files come unchanged from the test samples of the `evtx` project by Omer Ben-Amram
(https://github.com/omerbenamram/evtx, `samples/`), licensed under the Apache License 2.0
(https://www.apache.org/licenses/LICENSE-2.0).

- `Security_short_selected.evtx`: Security log (firewall and logon events)
- `Application_no_crc32.evtx`: Application log (with checksums left blank)
- `new-user-security.evtx`: Security log with a user account being created
