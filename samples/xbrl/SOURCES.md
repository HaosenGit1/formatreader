# Sample XBRL reports

Written for FormatReader (fictional companies and figures):
- `windco-2025.xbrl`: an XBRL instance in the US GAAP / SEC style (two years, one dimension, EPS unit).
- `windco-2025-ixbrl.xhtml`: Inline XBRL in the ESEF / IFRS style (comma decimals, scale, sign), with a
  script that must never run when the document is shown.
